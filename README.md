# Pacman Game in Java 🎮

A terminal-based Pacman game built using Java and Object-Oriented Programming concepts. The game features player movement, ghost movement, score tracking, and a text-based maze system.

## Features
- Terminal/console-based gameplay
- Text-based maze layout
- Player movement controls
- Ghost movement system
- Collision detection
- Score tracking
- OOP-based structure

## Technologies Used
- Java
- Object-Oriented Programming (OOP)

## Files
- `Pacman.java` → Main game source code
- `maze.txt` → Maze layout containing walls and movement paths

## OOP Concepts Used
- Classes & Objects
- Inheritance
- Abstraction
- Polymorphism
- Encapsulation

## Future Improvements
- GUI version using Java Swing/JavaFX
- Improved ghost AI
- Multiple levels
- Sound effects and animations

## How to Run
1. Compile the Java file:
```bash
javac Pacman.java
```

2. Run the game:
```bash
java Pacman
```
